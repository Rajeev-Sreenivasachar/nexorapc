# FBLA guideline check

Reviewed October 18, 2026.

## What was verified

- The official Florida FBLA Introduction to Programming page describes the event as a high-school event for students in grades 9 and 10 and allows teams of one to three members.
- The page describes a pre-judged program and says competitors must follow copyright rules.
- The version visible during this review still displayed a **2024–2025** topic and stated that the program must be prepared by the competitors without help.

Official links:

- [Florida FBLA: Introduction to Programming](https://www.floridafbla-pbl.com/fbla-event-introduction-to-programming)
- [Florida FBLA: Competitive Event Guidelines](https://www.floridafbla-pbl.com/competitive-event-guidelines)
- [National FBLA competitive events](https://www.fbla.org/divisions/fbla/fbla-competitive-events/)

## Important limitation

The repository did not include an official current-year event PDF, rubric, honor code, or AI-assistance policy. The public Florida page appeared outdated, so this project cannot claim confirmed compliance with the 2026–2027 rules.

Before submission, the team should obtain the current files from its adviser or official FBLA portal and confirm:

1. The current event topic and required deliverable.
2. Whether a hosted website is allowed or a locked cloud-storage upload is required.
3. What outside or generative-AI assistance is permitted and how it must be disclosed.
4. Copyright, citation, presentation-time, and file-format rules.
5. State and national deadlines.

If the current rules prohibit outside implementation help, this code must not be submitted as competitor-only work. The team should use it only as a learning reference, rebuild allowed portions themselves, and follow the adviser’s guidance.
