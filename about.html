Our student project

PC building, made easier to understand.

Nexora is a fictional PC component retailer created for the FBLA Introduction to Programming competition.

Why we built it

Choosing computer parts can feel like decoding a wall of model numbers. Nexora organizes those choices and shows the programming logic behind shopping, saving data, and checking compatibility.

How it helps

Visitors can search a catalog, compare specifications, save a cart, plan a build, and see exactly which compatibility rules were checked.

How it was developed

The project uses HTML5 for structure, CSS3 for the responsive interface, and readable vanilla JavaScript for data, interactions, local storage, and API requests.

What is real and what is a demo?

The programming features are functional: filters, cart calculations, browser storage, saved builds, compatibility checks, and the server-side Gemini connection. Product names and core specifications represent real hardware, while prices, availability, the store identity, and all shopping activity are demonstration data. Nexora does not accept orders or payments.
