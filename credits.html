Catalog credits.

Nexora separates hardware data, dated reference prices, retailer re-check links, and product imagery so each can be updated honestly.

Hardware and price snapshot

The expanded catalog was seeded from the open-source docyx PC Part Dataset, last updated July 23, 2025. Its USD values are shown as dated reference snapshots, not guaranteed current offers or Nexora inventory. Two SAPPHIRE GPU entries were checked against their exact Newegg listings on October 18, 2026.

Retailer re-check links

Each product includes a Newegg search link based on its model designation. Visitors must confirm the exact seller, model number, price, availability, shipping, and return policy before making a real purchase.

Homepage photography

The homepage mosaic uses the images added by the Nexora development team. Exact supplied image URLs: gaming PC, motherboard, graphics card, desktop PC setup, motherboard with GPU, and PC interior. The memory image was embedded directly in the homepage as WebP data, so it does not have a separate source URL in the project.
